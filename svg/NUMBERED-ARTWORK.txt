New route example:
svg/turuq/03/heading.svg
Add its exact Arabic name under "turuq" in svg/catalog.json, for example:
"03": "YOUR ARABIC ROUTE NAME"
Use the same number and name in the Asaneed route editor.
Do not reuse one route number for a different route.
Custom routes require their own COMPLETE sanad to the Prophet; the app does not append the default Shatibiyyah/Durrah chain.

Book names are mapped under "books" in svg/catalog.json.
The book name in Asaneed must match the catalog name (Arabic vowel marks are ignored).
Missing artwork falls back to the existing text; never upload placeholder graphics as real headings.

After changes, double-click Upload-Changes.cmd, then Update GitHub files in Asaneed.
